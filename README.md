# 🛠️ Softwares I Use

A clean overview of my personal/indie game development stack and how it maps to enterprise studio tools.

---

## 🎮 Personal & Indie Game Dev Stack

### 1. Core Development (`Unity` + `AI` + `GitHub`)
- **Unity:** Game engine for building, prototyping, and shipping.
- **Antigravity IDE (AI):** Agentic coding, debugging, planning, and automating repetitive workflows directly in the repo.
- **GitHub:** Version control (`git`), backups, and release history.

### 2. Documentation & Task Management (`Notion` + `Google Docs` + `Google Sheets`)
- **Notion:** Visual task & bug management (Kanban/Database views) with sandboxed AI API access for syncing programming/bug tasks at `git push`.
- **Google Docs:** Game Design Documents (GDD) and long-form technical documentation.
- **Google Sheets:** Game data tables, economy/damage math, and CSV/JSON balancing exports.

### 3. Team Communication (`Discord`)
- **Discord:** Used when collaborating with team members or playtesters (voice channels, 60fps screen sharing, and forum threads).

---

## 🏢 Enterprise / Studio Equivalents (`10–50+` People)

When working in larger studios or corporate environments, the indie stack maps directly to these enterprise tools:

| Category | My Personal / Indie Stack | Enterprise / Studio Equivalent | Why Companies Use the Enterprise Version |
| :--- | :--- | :--- | :--- |
| **Task & Bug Tracking** | **Notion** *(Databases / Kanban)* | **Jira** | Enforces strict workflow gates, QA bug pipelines, sprint analytics, and scales to `50,000+` tickets. |
| **Docs & Internal Wiki** | **Google Docs / Notion** | **Confluence** | Granular enterprise page permissions, approval sign-offs, and two-way live ticket syncing with Jira. |
| **Data & Spreadsheets** | **Google Sheets** | **Excel / Google Sheets** | Heavy number crunching, formulas, and localization tables. |
| **Chat & Calls** | **Discord** | **Slack / Microsoft Teams** | Corporate SSO (`Okta`), legal/compliance auditing, and Office 365 calendar/email bundling. |
